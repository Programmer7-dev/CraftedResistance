Privacy Policy

Last updated 18 October 2026

The short version: this website does not collect, store, or transmit your personal data. There are no accounts, no analytics, no cookies, and no tracking of any kind.

What this website does and does not do

This site is made of static HTML, CSS, JavaScript, and image files. It has no server-side code, no database, and no user accounts. Nothing you do here is recorded or sent to us, because there is nowhere for it to be sent.

  • No analytics or telemetry scripts
  • No cookies, local storage, or advertising identifiers
  • No sign-up, login, or profile
  • No contact form that stores what you type

Third parties that are contacted when you leave this site

The site loads its fonts from Google Fonts, and links out to Discord and GitHub. Those services have their own privacy policies and are governed by them, not by this page. We have no access to whatever they collect.

  • Google Fonts — font files are requested from fonts.googleapis.com, so Google receives your IP address as part of serving them. Google's privacy policy
  • Discord — the community invite runs on Discord, which collects account and usage data under Discord's own terms. It is not connected to this website or to your downloads. Discord's privacy policy
  • GitHub — game builds are hosted as GitHub Releases, so downloading a build sends your request to GitHub. GitHub's privacy statement

Hosting logs

The site is served from GitHub Pages. Like any web host, GitHub may keep standard server logs (such as IP address and request time) for security and abuse prevention. That processing is covered by GitHub's privacy statement, not by this policy.

The game itself

The game is a single-player desktop and Android application. It runs locally and stores its settings and saved worlds on your own machine, in folders you choose during setup. Uninstalling removes those files.

When you first run the game, it registers the craftedresistance:// URL scheme on your computer so that the Play now button on this site can start it. This is a local change to your own machine and is not reported anywhere.

Children

The game is not directed at children under 13, and this site does not knowingly collect data from anyone, of any age.

Changes to this policy

If this policy changes, the date at the top of the page will be updated. Because we hold no data about you, there is no way to notify you directly — please re-read it if you return to the site later.

Contact

Questions about this policy can be raised in the community Discord.
