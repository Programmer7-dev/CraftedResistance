Getting started

First launch

The download button does nothing. Why?

Either the build URL has not been published yet, or your browser is blocking the file. If the button is greyed out, there is no build for your platform in the selected version. The craftedresistance:// launch button is different: it needs the game installed and may ask your browser for permission to open an external app.

Windows says the app is unsafe, or SmartScreen blocked it.

The installer is not code-signed yet, so Windows shows a SmartScreen warning for a new, low-reputation file. Choose More info, then Run anyway, once you have checked the SHA-256 on the Windows card. If you would rather not bypass the warning, wait for a signed release.

How do I run the Linux build?

Download the .AppImage, mark it executable with chmod +x CraftedResistance-1.0-x86_64.AppImage, then run it with ./CraftedResistance-1.0-x86_64.AppImage. Nothing is installed system-wide, so deleting the file removes the game.

Does the game work on other Linux distros?

Ubuntu is the tested target. The AppImage is self-contained and is the better bet on Debian, Fedora and Arch, but you may need to install graphics drivers yourself. Report anything that breaks in the Discord.

How do I install the Android build?

Download the APK, open it, and allow installs from your browser or file manager when Android asks. It is signed with the Crafted Resistance release key, so it installs like any sideloaded app. Play Protect may warn about apps from outside the Play Store — tap Install anyway if the SHA-256 matches the Android card. Worlds, settings and progress are stored on the device.

How do I check a file's SHA-256?

Compare the hash on the platform card with one computed on your machine. On Windows PowerShell: Get-FileHash .\CraftedResistance-1.0.exe -Algorithm SHA256. On macOS or Linux: shasum -a 256 CraftedResistance-1.0.apk. They must match exactly; if they do not, delete the file and download it again.

Is there an Android or iOS build?

Yes for Android. The signed APK runs on Android 13 (API 33) or newer and has the same features as the desktop build. There is no iOS build: Apple requires a paid developer programme to distribute apps outside the App Store, and we are not pursuing that right now.

Can I play without installing?

Not at the moment. The craftedresistance:// launch button assumes the desktop build is already installed on your machine.

The game crashes or looks wrong on my machine.

Report it in the Discord with your OS version and GPU. Early builds are rough, and bug reports from testers are the fastest way to get things fixed before release.
