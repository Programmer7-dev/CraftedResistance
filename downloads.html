Getting started

First launch

The download button does nothing. Why?

Two common causes. Either the build URL has not been published yet, or your browser is blocking the custom protocol. On desktop browsers you can usually allow a site to open an external app from the icon in the address bar.

How do I run the Linux build?

Unzip the AppDir bundle wherever you want it, open the folder, and double-click the executable — or run it from a terminal with ./CraftedResistance. Mark it executable first with chmod +x CraftedResistance. Nothing gets installed system-wide, so delete the folder to uninstall.

Does the game work on other Linux distros?

Ubuntu is the tested target. The AppImage-style bundle is self-contained and is the better bet on Debian, Fedora and Arch, but expect to install graphics drivers yourself. Report anything that breaks in the Discord.

How do I install the Android build?

Download the APK above, open it, and allow installs from your browser or file manager when Android asks. It is signed with the Crafted Resistance release key, so it installs like any sideloaded app. Worlds, settings and progress are stored on the device.

Is there an Android or iOS build?

Yes for Android. The signed APK above runs on Android 13 (API 33) or newer and has the same features as the desktop build. There is still no iOS build as Apple just cares about their ecosystem too much and unsigned .ipas cannot be run on iOS devices

Can I play without installing?

Not at the moment. The craftedresistance:// launch button assumes the desktop build is already installed on your machine.

The game crashes or looks wrong on my machine.

Report it in the Discord with your OS version and GPU. Early builds are rough, and bug reports from testers are the fastest way to get things fixed before release.
